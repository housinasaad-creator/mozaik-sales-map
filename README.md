# Mozaik Ofset – Saha Satış Haritası / خريطة مبيعات موزاييك

Field-sales map for Mozaik Ofset (Gaziantep): restaurants, cafes, fast food, pizza, burger, döner and sweet shops.
Visit results (deal / pending / refused), notes, photos and a Turkish management report. Arabic / Turkish interface.
Access is protected by a team code that is checked on the server (Supabase).
